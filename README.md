# Karepaw B2B Pet Product Sourcing Website

English-language static website for Karepaw, serving wholesale buyers and pet brands.

## Preview locally

Open `dist/index.html` in a browser. The site uses relative asset paths and does not need a build step.

## Website content

- Six pet product categories, including an elevated mesh pet cot.
- Custom options for size, material, color, logo, and packaging.
- MOQ: 100 pieces per product; quantities cannot be combined across products.
- Sample service, standard testing and certification documents, supplier screening, product assortment planning, quality inspection, and export logistics.
- Inquiry form drafts an email to `sales01@karepaw.com`; the visitor must send it from their mail app.

## Hosting

The static site document root is `dist/` (see `.openai/hosting.json`). The target custom domain is `karepaw.com`; DNS records have not yet been configured.

The current wordmark and paw mark are a draft. Confirm product specifications and any named compliance claims before adding them.
